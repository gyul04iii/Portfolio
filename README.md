# Portfolio — Park Gyuri

비즈니스 블루 테마의 인터랙티브 원페이지 포트폴리오 사이트입니다.

## 🎨 Features

- **커스텀 커서 애니메이션**: 마우스를 따라다니는 도트 + 링 커서
- **타이핑 효과**: 역할이 자동으로 변경되는 Hero 섹션
- **스크롤 인터랙션**: 페이드인, 패럴랙스, 타임라인 슬라이드
- **프로젝트 필터링**: 카테고리별 실시간 필터
- **완전 반응형**: 모바일/태블릿/데스크톱 최적화

## 🚀 Tech Stack

- HTML5
- CSS3 (CSS Variables, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter, Playfair Display)

## 💻 Development

```bash
# Clone repository
git clone https://github.com/gyul04iii/Portfolio.git

# Open in browser
open index.html
```


## 🎯 Sections

1. **Hero** — 타이핑 효과, 부유 파티클, 통계 카운터
2. **About** — 자기소개 및 정보
3. **Skills** — 기술 스택 프로그레스 바
4. **Experience** — 타임라인 형식 경력
5. **Projects** — 카테고리 필터링 프로젝트 카드
6. **Contact** — 연락처 정보 및 폼
